## Prerequisites

- Laptop: Windows 10/11 (WSL2 recommended), macOS 12+, or Ubuntu 22.04+
- Docker Desktop installed (for local environment)
- Admin / sudo rights on the machine
- Telegram account + phone with WhatsApp installed
- Free Groq account at https://console.groq.com (no credit card needed)
- Free accounts: https://agentmail.to and https://www.firecrawl.dev
- Docker Desktop installed (Windows 10/11, macOS 12+, or Ubuntu 22.04+)
