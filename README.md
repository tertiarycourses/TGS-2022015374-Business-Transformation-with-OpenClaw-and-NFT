## About the course

Autonomous AI Agents with OpenClaw equips learners to build, deploy, and manage goal-driven AI agents that can plan actions, use digital tools, retain contextual memory, and complete multi-step work with appropriate human oversight.

Learners connect models, channels, tools, and skills; automate work with cron and heartbeat; monitor performance and cost; and apply security guardrails to reliable business workflows.

## Learning outcomes

By the end of the course, learners will be able to:

- deploy OpenClaw on a cloud VPS or local Docker Desktop environment;
- connect suitable model providers and messaging channels;
- integrate tools, APIs, and reusable skills;
- schedule and monitor autonomous workflows;
- apply secure configuration, allowlists, sandboxing, and audit controls;
- optimise model usage and operating cost; and
- evaluate and demonstrate an end-to-end business automation use case.

## Topics covered

- Exploring OpenClaw and the autonomous AI agent landscape
- Evaluating OpenClaw applications and business opportunities
- Designing OpenClaw workflows and managing implementation risks
- Tools, APIs, channels, skills, memory, and scheduled automation
- Monitoring, cost optimisation, security, and human oversight

## Lab environments

Students may use either a Hostinger VPS running Ubuntu 22.04 LTS or Docker Desktop on a local Windows, macOS, or Ubuntu machine.
